۴۵ افکت حرفه‌ای برای ریلزهایت،
فقط با یک پرامپت

افکت را ببین، پرامپتش را کپی کن و داخل Claude Code بفرست. همه‌ی پیش‌نمایش‌های این صفحه روی ویدیوی خودم ساخته شده‌اند، با همان کد واقعی افکت‌ها.

چطور استفاده کنم؟

راهنمای کامل نصب (مک و ویندوز)
  1. ۱یک بار Claude Code و ابزارها را نصب کن.
  2. ۲یک بار مهارت افکت‌ها را اضافه کن.
  3. ۳ویدیو را داخل Claude بکش و پرامپت افکت را بفرست.
  4. ۴خروجی آماده‌ی اینستاگرام بگیر.

کتابخانه‌ی افکت‌ها

جای [...] را با متن خودت عوض کن. زمان‌ها (ثانیه) را هم می‌توانی تغییر دهی یا بنویسی «وقتی گفتم ...».

افکتی پیدا نشد. کلمه‌ی دیگری امتحان کن (مثلاً: zoom، متن، گرید).
