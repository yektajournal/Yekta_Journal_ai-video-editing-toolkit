نصب و راهنمای قدم‌به‌قدم

افکت‌های حرفه‌ای مثل orbit، spotlight و glass-widgets را با کمک Claude Code روی ویدیوهای خودتان بگذارید.

چطور کار می‌کند؟ پیش‌نیازها نصب روی مک نصب روی ویندوز پرامپت‌ها رفع خطا 🎬 کتابخانه‌ی ۴۵ افکت

چطور کار می‌کند؟

Claude Code دستیار هوش مصنوعی Anthropic است که روی کامپیوتر شما برنامه نصب می‌کند و دستور اجرا می‌کند؛ شما فقط به زبان ساده می‌گویید چه می‌خواهید.

پروژه‌ی claude-video-effects یک «مهارت» (Skill) برای Claude Code است. بعد از نصب، ویدیو را به Claude می‌دهید و می‌نویسید مثلاً /effects orbit from 3 to 6 seconds. Claude صورت شما را پیدا می‌کند، افکت را طوری می‌گذارد که روی صورتتان نیفتد و یک فایل جدید کنار ویدیوی اصلی می‌سازد.

  1. ۱نصب ابزارها (یک بار)
  2. ۲نصب مهارت افکت‌ها (یک بار)
  3. ۳دادن ویدیو و انتخاب افکت
  4. ۴خروجی مخصوص اینستاگرام

پیش‌نیازها

بر اساس فایل‌های خودِ پروژه‌ی اصلی (README، requirements.txt و scripts/setup.sh):

  • Claude Code دستیاری که همه‌ی کارها را انجام می‌دهد. به اشتراک پولی Claude (مثل Pro یا Max) نیاز دارد.
  • Git برای دانلود پروژه از گیت‌هاب. روی ویندوز، Claude Code خودش هم به آن نیاز دارد.
  • Python ۳٫۱۰ یا جدیدتر زبانی که افکت‌ها با آن نوشته شده‌اند (۳٫۱۲ پیشنهادی).
  • FFmpeg + ffprobe موتور ساختن و خواندن فایل ویدیو.
  • کتابخانه‌های پایتون numpy، opencv-python، pillow و mediapipe. خودکار نصب می‌شوند.
  • faster-whisper (اختیاری) برای پیدا کردن زمان هر کلمه. بار اول خودکار نصب می‌شود.
  • Homebrew / winget ابزار نصب برنامه روی مک / ویندوز.
  • حساب GitHub (اختیاری) برای دانلود لازم نیست.

💡 لازم نیست همه را دستی نصب کنید: پرامپت شماره‌ی ۱ از Claude می‌خواهد خودش بررسی و نصب کند.

نصب روی مک (macOS)

قدم ۱: ترمینال را باز کنید

⌘ Command + Space را بزنید، بنویسید Terminal و Enter بزنید.

قدم ۲: نصب Claude Code

curl -fsSL https://claude.ai/install.sh | bash

بعد بنویسید claude و وارد حسابتان شوید. یا نسخه‌ی دسکتاپ را از claude.ai/download بگیرید و از تب Code استفاده کنید.

قدم ۳: نصب Git، Python و FFmpeg

اگر Homebrew ندارید، اول از brew.sh نصبش کنید. بعد:

brew install git python@3.12 ffmpeg

قدم ۴: نصب مهارت افکت‌ها

git clone https://github.com/Vibha-Ramprakash/claude-video-effects ~/.claude/skills/effects

قدم ۵: Claude Code را ببندید و دوباره باز کنید

حالا /effects آماده است. بار اول ۱ تا ۳ دقیقه طول می‌کشد تا کتابخانه‌ها نصب شوند.

نصب روی ویندوز

قدم ۱: PowerShell را باز کنید

روی Start کلیک کنید، بنویسید PowerShell و بازش کنید.

قدم ۲: نصب Git

Claude Code روی ویندوز به Git for Windows نیاز دارد (Git Bash هم همراهش می‌آید):

winget install --id Git.Git -e

بعد PowerShell را ببندید و دوباره باز کنید.

قدم ۳: نصب Claude Code

irm https://claude.ai/install.ps1 | iex

بعد بنویسید claude و وارد حسابتان شوید.

قدم ۴: نصب Python و FFmpeg

winget install Python.Python.3.12
winget install ffmpeg

دوباره PowerShell را ببندید و باز کنید.

قدم ۵: نصب مهارت افکت‌ها

git clone https://github.com/Vibha-Ramprakash/claude-video-effects $HOME\.claude\skills\effects

قدم ۶: Claude Code را ری‌استارت کنید

تمام! حالا /effects کار می‌کند.

پرامپت‌های آماده

پرامپت‌ها عمداً انگلیسی هستند تا Claude دقیق‌ترین نتیجه را بدهد. کپی کنید و داخل Claude Code بفرستید. هرجا [...] دیدید، با اطلاعات خودتان عوض کنید.

۱) نصب ابزارها

I'm a beginner with no programming experience. Please check whether these are installed on my computer: Git, Python 3.10 or newer, FFmpeg and ffprobe. Install anything that is missing (on macOS use Homebrew, on Windows use winget). Explain each step in one simple sentence, and ask me before running anything that needs my password or admin rights. When you're done, show me the installed version of each tool.

۲) نصب و راه‌اندازی افکت‌ها

Install the video effects skill from https://github.com/Vibha-Ramprakash/claude-video-effects into ~/.claude/skills/effects (on Windows use $HOME\.claude\skills\effects). If the folder already exists, update it with git pull instead of deleting it. Then run its scripts/setup.sh once and wait until it prints READY. If it prints NEED_FFMPEG or NEED_PYTHON, install what's missing and run it again. Finally, tell me if I need to restart Claude Code.

۳) گذاشتن افکت روی ویدیوی خودتان

اول ویدیو را داخل پنجره‌ی Claude بکشید (Drag & Drop). بعد یکی از این‌ها:

/effects orbit from 3 to 6 seconds
/effects spotlight when I say "[a word from your video]", with the word [YOUR WORD] glowing behind me
Use the effects skill on my video [drag your video here]. Add "glass-widgets" for the first 3 seconds, then "backdrop-word" with the text "[YOUR WORD]" when I say "[a word from your video]". Before rendering, show me check frames and make sure nothing covers my face. Keep my original audio and save the result as a new file next to my video. Don't overwrite my original.

🎯 هر ۴۵ افکت را با پیش‌نمایش و پرامپت آماده در کتابخانه‌ی افکت‌ها ببینید.

۴) خروجی آماده برای اینستاگرام (۱۰۸۰×۱۹۲۰)

Take my rendered video [file name]_effects.mp4 and export an Instagram Reels version with FFmpeg:
- 1080x1920 (9:16). Scale to fit and crop if needed, never stretch.
- H.264 (libx264, High profile), pixel format yuv420p, 30 fps
- Video bitrate about 10 Mbps (maxrate 12M, bufsize 20M)
- AAC audio, 128 kbps, 48 kHz (keep the original audio)
- Add +faststart
Save it as [file name]_instagram.mp4 next to the original and don't overwrite any file. Then run ffprobe and show me the resolution, codec, fps and bitrate to confirm.

یا اگر می‌خواهید خودتان در ترمینال اجرا کنید:

ffmpeg -i input_effects.mp4 -vf "scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920,fps=30" -c:v libx264 -profile:v high -pix_fmt yuv420p -b:v 10M -maxrate 12M -bufsize 20M -c:a aac -b:a 128k -ar 48000 -movflags +faststart output_instagram.mp4

۵) رفع خطا

I got this error while using the effects skill:

[paste the full error here]

Explain in simple words what it means, find the cause, fix it, and tell me exactly what you changed. Don't delete or overwrite my videos.
The effect doesn't look right: [describe what you see, e.g. "the word covers my face" or "it's too fast"]. Please show me check frames, adjust the plan, and render again as a new file.

خطاهای رایج

ffmpeg: command not found یا NEED_FFMPEG

FFmpeg نصب نیست یا ترمینال هنوز آن را نمی‌شناسد. مک: brew install ffmpeg، ویندوز: winget install ffmpeg. بعد ترمینال را ببندید و باز کنید.

NEED_PYTHON

پایتون نیست یا قدیمی‌تر از ۳٫۱۰ است. مک: brew install python@3.12، ویندوز: winget install Python.Python.3.12

Claude دستور /effects را نمی‌شناسد

مطمئن شوید پوشه دقیقاً ~/.claude/skills/effects است و فایل SKILL.md داخلش هست، بعد Claude Code را ببندید و باز کنید.

brew: command not found (مک)

Homebrew را از brew.sh نصب کنید.

winget یا bash روی ویندوز شناخته نمی‌شود

برای winget، برنامه‌ی App Installer را از Microsoft Store به‌روز کنید. برای bash، Git for Windows را نصب کنید: winget install --id Git.Git -e

افکت یا نوشته روی صورت افتاده

پرامپت دوم بخش «رفع خطا» را بفرستید تا Claude برنامه را اصلاح کند.

بار اول خیلی طول می‌کشد

طبیعی است: کتابخانه‌ها و مدل تشخیص کلمه نصب می‌شوند. ۱ تا ۳ دقیقه صبر کنید.

  • ویدیوی عمودی که خودتان در کادر هستید بهترین نتیجه را می‌دهد.
  • هر افکت را کوتاه نگه دارید (۱٫۵ تا ۴ ثانیه).
  • این افکت‌ها نسخه‌ی اولیه هستند؛ قبل از پست کردن خروجی را نگاه کنید.
  • صدا و زیرنویس اضافه نمی‌شود؛ آن‌ها را در CapCut اضافه کنید.
